**Milestone:** M1 · **Owner:** kernel-dev · **Status:** ready ·
**Binding rules:** R1, R3, R5, R6, R9, R10, R11 (+ Law 2/3, constitution 02/03) ·
**LOC ceilings:** 900 for `crates/jinnd-ledger` · forward-iterator delta in

## Scope

### `crates/jinnd-ledger`
- **Append-only SQLite event log** (R6, Law 2): every kernel-boundary event —
  effect registration/withdrawal outcomes, fiber transitions, service
  provide/withdraw, amendment attempts (accepted AND refused), write-backs,
  recorded errors — lands as a typed, serde-defined ledger event (R3) with
  monotonic sequence, timestamp, and **profile-entry attribution** (every event
  traceable to the entry/fiber that caused it; the audit's error→entry
  requirement). Device-local, append-only: no destructive compaction, no
  UPDATE/DELETE paths in v0.1 (constitution bounds).
- **Receipts** (constitution 02): appends return receipts; a receipt is proof of
  durability (WAL, synchronous append or batched with an explicit flush seam —
  document the choice and its honesty).
- **Revert support** (constitution 03, Law 3): keyed exactly-once inverse
  protocol over ledger events + effect inverses — same idempotency key on retry;
  executable witnesses checked after each inverse; the pending-revert state
  machine EXACTLY as ratified: `pending-revert` not closable by declaration,
  resolves only via same-key inverse success + witness pass → `reverted`, or
  operator-confirmed declared compensator → `compensated`, never `reverted`;
  unless compensation satisfies the original equivalence witness the branch
  stays marked unclean. No time-range revert in v0.1.
- **Dispatch-trace event class RESERVED** (typed variant + schema now, emission
  wired when the event bus gains its ledger tap — may be a stub emitter behind
  the seam; the class existing and being append-tested is the deliverable).
- **Pure-core discipline**: the crate takes a database path/handle; no ambient
  authority, no globals. Async-first (R1): appends never hold a lock across
  plugin-facing code; rusqlite's blocking calls are confined behind a dedicated
  writer task or spawn_blocking seam — no executor blocking in kernel async
  paths, documented.

### `crates/jinnd-effects` — forward effect-iterator (audit F8)
- Iterator effects per paper Def 51/52 + Alg 1: a stepwise effect yields
  inverses progressively; a **target-staleness guard runs at every yield
  boundary** (L-Iter/L-Divert granularity) enabling partial rollback within a
  transition; a plain (non-iterator) effect installs **all or none**. This is
  what the 13 red `cordis_dispose` cases await.

### `crates/jinnd-adapter` wiring
- Wire ledger + revert + forward iterator through the kernel facade. The
  ledger/dispose/revert-citing FACADE_GAP cases become executable; remaining
  reds keep exact recorded reasons.

## Facade

Minimal **additive** delta authorized: ledger read surface (query events by
entry/fiber/sequence), receipt type, revert entry points + resolution states,
iterator-effect registration shape. Exact items documented in the report.
Prefer the smallest surface the cases need (R12).

## Round protocol (codified pattern)

Round 1 delivers crates + wiring + claimed-greenable list; the COO then
dispatches the verifier body/adoption session (ledger/dispose/revert prose IOUs
become executable bodies; catalog + expected-green verifier-owned, rev-8
adoption semantics); subsequent rounds fix findings against real bodies.

## Acceptance

- Append-only proven behaviorally (no mutation path exists; a reopened ledger
  replays identically); receipts durable across a process-death simulation.
- Revert: keyed exactly-once proven (same-key retry is idempotent, distinct-key
  refused); witness failure → branch stays `pending-revert`, visibly; the
  three-state resolution machine behaviorally pinned; a compensator that fails
  the original witness leaves the branch marked unclean.
- Forward iterator: mid-iteration divert rolls back exactly the yielded prefix;
  plain effects all-or-none; cancellation between yields honored (R1).
- Attribution: a failing entry's recorded error is reachable from its ledger
  events by entry id.
- New verifier-validated greens with catalog + expected-green verifier-owned;
  check-ratchet.sh green; remaining reds at designed sites with recorded
  reasons.
- Gates: fmt, clippy -D warnings, build, test, ratchet — paste real tails; loom
  where interleaving-sensitive (writer-task seam); miri on touched crates
  (rusqlite FFI exclusions listed with reasons).
- LOC within ceilings; files under 300 lines; two-key: zero implementer touches
  under tests/invariants/.

## Out of scope

Wasm host, capability broker, event-bus ledger tap emission (class reserved
only), grants/signing, time-range revert, remote/synced ledgers, any facade
change beyond the authorized delta.
