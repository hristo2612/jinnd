# Packet M1-P0 — The Test Port (verifier-owned)

**Milestone:** M1 · **Owner:** jinn-verifier (NOT kernel-dev — two-key rule) ·
**Status:** ready to start · **Binding rules:** R2, R3, R9, two-key rule.

## Scope

Port the executable semantics into `tests/invariants/`, landing **red** (no kernel
code exists; red is the backlog, not failure):

1. **The Cordis v4 spec suite** — translate the behavioral specs from
   the Cordis reference checkout's `packages/core/tests/*.spec.ts` (private annex; and the
   loader's `isolate`/`group`/tree-diff specs) into Rust integration tests against
   the future kernel API (define the minimal API surface as a `jinnd-api` test
   facade crate of traits/types — types only, no implementation).
   Priority order: `fiber.spec.ts` (the inertia-lock trio FIRST — mid-flight
   dependency-swap coalescing), `dispose.spec`, `isolate.spec`, `events.spec`,
   `service.spec`. Skip: `shadow.spec`/`invoke.spec` proxy-machinery tests (we use
   handles per R4 — write handle-semantics equivalents instead), decorator tests.
2. **I1–I4 invariant tests** — `invariant_recovery.rs`, `invariant_ordering.rs`,
   `invariant_progress.rs`, `invariant_confluence.rs` per SOURCE-OF-TRUTH §4,
   including: recovery under mid-load failure (I1), consumer-may-call-dying-provider
   during teardown (I2), cycle → clean inactivity + quiescence (I3), and
   randomized-history vs fresh-boot state equivalence (I4, proptest).
3. **Hazard tests (R9)** — tests asserting the ABSENCE of the banned behaviors
   (emit does NOT abort remaining listeners; async result is NOT treated as bailed;
   failed fibers do NOT auto-retry on an unchanged environment).

## Acceptance

- Suite compiles against the `jinnd-api` facade; every test red or explicitly
  `todo`-tagged with a reason; zero tests green by vacuity (a test that passes with
  no kernel is a broken test).
- Each ported test cites its TS origin (file + test name) or paper theorem in a
  doc comment.
- CI's invariant-suite gate flipped from advisory (`|| true`) to hard.
- LOC budget: tests are exempt from kernel budgets, but the facade crate ≤ 400 LOC.

## Out of scope

Any kernel implementation. Any change outside `tests/`, `crates/jinnd-api`
(facade), and CI's gate flip.
