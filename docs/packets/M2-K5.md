## Finding 16 → quiesce before seal (suspend AND dispose)

At 4eb4a93 the seal refuses post-seal registrations (I1 backstop, correct)
but does not drain the guest call in flight first: a planned SIGINT landing
mid-`handle-event` tears the tick (state advanced, run record registered,
history append refused `InactiveContext`, handler `PluginFailed`). Rule:
on suspend and on dispose, **await the in-flight guest call under the
existing guest deadline, THEN seal**; the seal refusal remains the backstop
only for a handler that outlives the deadline. Red-first: a fixture whose
handler makes N related effects, suspended mid-handler, must land all N
(drained) — never a prefix.

## Finding 17 → recognize the daemon's own write-back by what it WROTE

`Daemon::reload` guards against reconciling its own write-back echo by
comparing delivered text to text it RE-READS from disk after every apply —
so an external edit that lands during a reconcile is captured as "own
echo" and swallowed with an all-empty `reconciled` success line; identical
rewrites can never escape (this is what defeated finding 12's mitigation).
Rule: the daemon recognizes its own write-back by the bytes/generation it
itself wrote (remembered at the save), never by re-reading a file another
writer may have replaced — OR drop the echo guard entirely and let the
loader's diff answer `unchanged` (implementer chooses; verifier judges
against the transcript). Red-first: an external edit landing during a
slow reconcile MUST be applied; an identical rewrite MUST reconcile
`unchanged`, never be skipped as an echo. An operator edit is never lost
under a success line (Law 2: the log records what happened).

## Finding 18 (+12 minimum) → watch before evidence

With a relative `--profile`, the daemon boot-reconciled (guests active,
`boot.json` + catch-up fire on disk and ledger) and THEN failed to arm the
watcher and exited 1. Refusing to serve unwatched is right; the ORDER is
wrong. Rule: canonicalize paths at startup and **arm the file watcher (or
refuse, with the error) BEFORE the boot reconcile writes any evidence**;
after the watcher is armed and the boot reconcile completes, emit one
machine-readable readiness line to stderr (finding 12's minimum — "booted;
watcher armed"). Red-first: relative profile path refuses before any
guest activates; readiness line appears only after the watcher is armed.
