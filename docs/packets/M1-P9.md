## Scope

### `crates/jinnd-daemon` — the `jinnd` binary
- **Production assembly ONLY**: profile path (arg/env) → loader → registry/
  fiber/effects/events → ledger (real SQLite path) → wasm host through the
  broker. The conformance-harness lane must NOT be compiled into this binary
  (P8's compile-gate proven again here at the binary level).
- **File watching**: an edit to the profile file triggers reconcile-by-id
  (debounced; a malformed save is a contained per-entry failure per the loader
  doctrine, never a crash, never a partial apply).
- **Operations**: structured tracing to stderr; graceful shutdown on SIGINT
  (dispose all → quiescence → ledger flush → exit 0); ledger path and profile
  path are the only required config. Nothing else — the daemon is a shell, not
  a feature (R10). No HTTP API in M1 (that is M3 parity work).

### Demo kit (fixtures, excluded from LOC counts)
- **Three toy plugins** (source in-repo under `demo/plugins/`, built to wasm
  components by a documented script): e.g. a `clock` provider, a `greeter`
  consuming it and providing a greeting service, a `scribe` listening to
  events and writing through a granted host contract. Between them they
  exercise provide/inject, events, effects with undos, and grants.
- **Demo profile** `demo/profile.json` mounting all three.
- **`docs/demo/M1-DEMO.md` runbook** — the exact operator script for the §7
  acceptance, each step with the command to run and what to observe:
  1. Boot `jinnd` with the profile → three plugins Active.
  2. Edit one entry's config → ONLY that fiber restarts (fiber uids shown
     before/after; siblings' uids unchanged).
  3. Hot-swap one plugin's wasm artifact → healthy swap replaces with
     old-warm-until-healthy; then a deliberately-broken artifact → automatic
     rollback, both ledger-recorded.
  4. Dispose one plugin → the ledger shows exactly what was undone.
  5. Revert a recorded effect by key → revert works; the ledger shows the
     receipt trail.
- **The demo is also a test**: `tests/demo/` (implementer-owned integration
  test, NOT under tests/invariants/) drives the daemon-assembled kernel
  through the same five steps headlessly, so the demo cannot rot.

## Acceptance

- `jinnd --profile demo/profile.json` boots to three Active wasm plugins on a
  fresh machine-independent path; SIGINT shuts down clean (quiescence + exit 0).
- Config edit restarts exactly the edited entry's fiber (uid evidence);
  siblings untouched.
- Hot-swap: healthy swap and failing-swap-with-rollback both demonstrated and
  ledger-recorded through the daemon path.
- Dispose shows exact undo trail in the ledger; keyed revert works with
  receipts.
- Headless demo test green; runbook steps reproduce it manually.
- Suite endgame: ratchet green with FACADE_GAP eliminated (green or
  adjudicated `V02_DEFERRED` with recorded bounds); full gates + loom/miri
  discipline as prior packets.
- Production binary provably excludes the harness lane; two-key clean; LOC
  within ceilings; files under 300 lines (src hard, tests soft).
