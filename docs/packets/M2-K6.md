## Scope

### Contract bundles (R12: additive, versioned; world → `jinn:plugin@0.4.0`)
- **`contracts/jinn-process` 0.1.0** — keep `run` (one-shot, convenience) and
  ADD the long-lived edition: `spawn(command, args, cwd?, env-policy) →
  handle`; `write-stdin(handle, bytes)`; `read(handle, stream: stdout|stderr,
  max) → bytes | would-block | eof`; `wait(handle, timeout-ms) → exit-status |
  running`; `kill(handle, signal)`. A spawned process is a **kernel
  registration** (lifecycle classification): released on suspend (killed,
  ledgered — a suspended incarnation cannot own a live child), killed on
  dispose; plugins re-spawn on activate. Reads are non-blocking with typed
  `would-block` (R1: no host call blocks across the guest deadline); the guest
  polls or is woken via the existing event surface — implementer chooses the
  minimal honest shape and documents it in the bundle README.
- **`contracts/jinn-net` 0.1.0** — keep `request` (outbound, one-shot) and ADD
  the server edition: `listen(addr) → listener` (loopback only in v0.1),
  `accept(listener) → conn | would-block`, `read(conn, max)`, `write(conn,
  bytes)`, `close(conn|listener)`. Listeners and connections are kernel
  registrations (released on suspend, re-listened on activate).
- **Grant scopes are typed and FAIL-CLOSED (M2-K2 law):** process scope =
  executable allowlist by canonical path prefix + env policy (inherit-none |
  allowlist); net scope = bind = loopback + port range, outbound = host
  allowlist. Malformed/wrong-type/undeclared scope REFUSES the grant with a
  ledgered per-entry error. No grant, no call. Default deny.
- Metadata declares effect classes and the lifecycle class per operation
  (world mutation vs kernel registration) exactly as `jinn-fs`/`jinn-clock` do.

### Host providers (`crates/jinnd-wasm`, registered by the daemon like HostFs)
- Tokio-native, R1-clean: no lock held across guest delivery; child I/O pumped
  by host tasks into bounded per-stream buffers (R9: bounded — a guest that
  never reads gets backpressure, not unbounded RAM); every spawn / exit /
  kill / listen / accept / close is a ledger event with entry attribution
  (Law 2).
- Grant enforcement at the single admission point per call (path canonicalized
  post-symlink for executables, same doctrine as K3 containment).
- `keystore` stays unprovided in this packet (finding 5 says process first;
  its card comes with the first real consumer — settings/secrets seam).
